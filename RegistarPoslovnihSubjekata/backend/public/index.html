Servis

Sudreg API — popis snimki

Snimi sve snimke na disk: za svaki snapshot_id s Sudreg API-ja preuzima promjene.jsonl i sve matične skupove (subjekti, tvrtka, sjedišta, …). Ako datoteka već postoji na disku, preskače se. Može trajati dugo — prati progress ispod. Diff susjednih snimki: za svaki uzastopni par ID (n→n+1) generira diffs/{n}_to_{n+1}/promjene.jsonl + meta.json (SCN diff) i automatski matične skupove u datasets/. Diff matičnih entiteta: samo datasets/*.jsonl za sve susjedne parove — jedan HTTP zahtjev po paru; potreban je promjene.jsonl u diff mapi.

Izrada JSONL na disku: dovoljna su tri zelena gumba gore (snimke → SCN diff → matični diff). Dolje: tablica, preuzimanje, PostgreSQL. Duplikati spremanja su u Napredno.
